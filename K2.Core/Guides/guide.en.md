@@@ dedicated:discord
# Discord voice profile (DisplayPad)

The Discord dedicated profile is the **live voice page**: while you're in a
Discord voice call it takes the pad over on its own and hands it back to your
normal profile when the call ends. Its slot holds no keys — the page is drawn
from the call itself.

## Prepare a Discord application

Voice control talks to the Discord **desktop app** through its local RPC
pipe, which needs your own Discord application (free). ("Send message" is the
exception — it only needs a channel webhook URL, no app.)

1. Open **discord.com/developers/applications** and click **New Application**.
2. **OAuth2 ▸ Redirects**: add `http://localhost:17564/callback`.
3. Copy the **Client ID**; click **Reset Secret** for the **Client Secret**.
4. Use the **Discord account…** button here, paste both, and click
   **Connect** — Discord asks you to authorize (you must be the app's owner).
   The Discord desktop app has to be running.

## Camera and push-to-talk

Discord has no RPC command for these, so K2 sends a keyboard shortcut
instead: press **Record**, type a combination, then set the **same** one in
**Discord ▸ Settings ▸ Keybinds** (Toggle Camera / Push to Talk). The
push-to-talk key is held down for exactly as long as you hold the pad key.

## How the profile behaves

- Created with **+ New profile ▸ Dedicated ▸ Discord**. It is **per pad** and
  lives in the *Dedicated profiles* list, not the normal one.
- It arms itself: joining a voice call opens the page; leaving the call
  closes it and restores the previous profile. A *Discord ▸ voice page* key
  also opens it on demand.
- The keys (mute, deafen, push-to-talk, camera, disconnect…) repaint live
  from Discord, so the mute icon stays correct even if you toggle mute inside
  Discord itself.
- **Return after N seconds**: if you switch to a normal profile mid-call, the
  voice page comes back on its own after that delay, like a screensaver. Off
  = it only returns on a new call or a *voice page* key.

@@@ dedicated:spotify
# Spotify profile (DisplayPad)

The Spotify dedicated profile keeps the current track on the pad's left 2×2
block (keys 0/1/6/7) and 8 media-control keys on the rest. Its **gear ▸
Configure** popup has three settings, saved **per pad**.

## Track data source

- **Local (Windows "now playing")** — reads the track from Windows itself.
  Works with just the Spotify desktop app open, no account needed, but only
  gives what Windows exposes (title, artist, album, a small cover).
- **Spotify account (Web API)** — reads it from Spotify directly: the real
  album name and a higher-resolution cover. Needs the account connected (the
  **Spotify account…** button, same window as the *Spotify* key action). If
  the Web API returns nothing — not connected, nothing playing, a free
  account with no active device — it **falls back to the local source** on
  its own.
- Either way, **playback control** (the 8 media keys) still goes through the
  system media keys / the Spotify actions — this setting only changes what
  the cover block shows.

## Cover layout

- **Cover across 4 tiles** — the album art fills the whole 2×2 block (the
  original look).
- **Cover on 1 tile + text** — the art shrinks to one tile; the other three
  show the **title**, the **artist** and the **album**. The mapping follows
  the pad's rotation, so it still reads correctly on a sideways-mounted pad.

## Long text

For the 1-tile layout, when a title/artist/album is wider than its tile:

- **Static** — one line, the font shrinks to a readable floor and then the
  end is trimmed with "…".
- **Scroll it like a ticker** — the line scrolls sideways and wraps around,
  like a scrolling LED sign. Only the fields that actually overflow scroll;
  short ones stay put.

@@@ spotify:account
# Spotify account — setup and limits

K2 has no Spotify app of its own, so you register your own (free) at
**developer.spotify.com/dashboard** and paste its **Client ID / Secret**
here. Add the Redirect URI **`http://127.0.0.1:17564/callback`** to the app,
then **Connect**.

## What needs what

- **Cover art + track info** — works on any connected account (and the
  *Local* source needs no account at all).
- **Play / pause, next / previous, shuffle, repeat, volume via the Web API**
  — need **Spotify Premium**. On a free account K2 falls back to the system
  media keys, which still work.
- **Like the current track, Save / remove from a playlist** — these hit
  Spotify's library endpoints, which **Development-mode apps are blocked from
  (403)** since 2025 unless your account is added under the app's **User
  Management**, or the app is granted **Extended Access**. Not fixable from
  K2 — it's a Spotify dashboard setting.

## If something 403s

- **"missing scope"** — a scope was added since you authorized. **Disconnect**
  then **Connect** again.
- **403 with the scope present** — the library/playlist block above. Add the
  account under **User Management** on the dashboard.
- **"Premium required"** — that command needs Premium; the media-key fallback
  covers transport.

- **Full clock** — one key shows the whole time. *Analog* is a round face,
  *Digital* is HH:MM on one line, *Vertical* stacks HH over MM. Each comes in
  a **24h** and a **12h** variant — pick the one you prefer.
- **Single field** — *Hours only* (24h / 12h), *Minutes only*, *Seconds
  only*: the key shows just that number, large. Put two or three side by side
  to spell the time out across several keys.
- **Date** — day / month instead of the time.

# Highlights — what K2 adds over Base Camp

Features K2 has that Mountain's Base Camp doesn't, and how to turn them on —
first the ones shared across devices, then per device.

## Appearance sections (Everest Max, Everest 60, MacroPad)

The **Appearance** sidebar section is K2-only and purely cosmetic: it
restyles how the device is drawn *in K2*, nothing is sent to the hardware.

- **Keycap color** / **legend color** — recolour the on-screen keys.
- **Keyboard frame** (Everest Max) — draw the chassis silver or black.
- **Edit individual keycaps** — tick it, then click a key on the image to
  give that one key its own colour and label in the preview.

Use it to make the on-screen keyboard match your real one, or a custom
build.

![The Appearance section on Everest Max — keycap / legend colour and the silver/black frame, preview only.](everest-appearance.png)

## Backlight auto-off

In each device's **Settings** section: turn the key backlight off after N
idle seconds and back on at the next key press. No K2 device firmware does
this by itself — it's a K2 software timer. (DisplayPad forces brightness to 0
instead; Makalu is excluded — its buttons send nothing K2 can see.)

## Key mappings — the full action catalog everywhere, display keys included

Every mappable key on every device — keyboard keys, MacroPad keys, DisplayPad
keys, and the **display keys** (Everest Max Media Dock keys and numpad screen
keys) — uses the same rich action catalog: run a program, open a URL or
folder, send a shortcut or a macro, control media, Multi Action, and the app
integrations (OBS, Twitch, Spotify, Discord, YouTube, Google Home, Python).

- Everest Max **display keys** (dock + numpad screen) and the **crown** are
  set by clicking them directly on the device image, not from the key list —
  then the normal action dialog opens.
- Base Camp limits several of these keys to a short built-in list; in K2 they
  take any action, with a generated or custom icon.

![Everest Max — the dock keys, the crown and the four numpad screen keys, each running an ordinary action (a calculator, an app, shortcuts).](everest-displaykeys.png)

@@@ highlights:displaypad
# Highlights — DisplayPad

## Dedicated profiles

Special panels that take the pad over on their own trigger and hand it back,
like a screensaver (the profile menu's own **Guide** has the full picture).
Create one with **+ New profile ▸ Dedicated**, then pick the app:

- **Spotify — now playing**: the top-left 2×2 block shows the current
  track's cover art, live.
- **Discord — voice call**: the live voice page takes over while you're in a
  call and leaves when it ends.

Both are per pad, and neither exists in Base Camp.

![The Dedicated profiles list, below the normal profiles.](dp-dedicated.png)

## Normal profiles tied to a program

**Right-click a profile ▸ Configure profile** and set a linked program: that
profile then activates automatically when the program starts.

- **Only while focused** — switch back the moment the program loses focus.
- **Restore on close** — return to the previous profile when the program
  exits.

Leave the program blank for a plain manual profile.

![Configure profile — the Launch executable field plus the focus-only and restore-on-close options.](dp-profile-exe.png)

## Emoji and Emoji browser

- **Emoji** action — a key that types one emoji you pick.
- **Emoji browser** action — a key that turns the whole pad into a
  scrollable emoji picker painted on the device (categories, then emoji, with
  back / close / scroll keys). Nothing is stored; the grid returns when you
  leave it.

## Live tiles

Keys that show live data instead of a fixed icon, repainted from the PC:

- **Clock** — analog / digital / vertical, 24h or 12h, or single-field tiles
  (hours / minutes / seconds) to spell a big clock across several keys.
- **PC monitor** — CPU / GPU / RAM / disk load or temperature, network
  throughput, or any hardware sensor via the sensor picker.
- **Speed test** — press to run a test; download / upload / ping keys
  refresh together.

## Rotation (Settings) — and how the layout adapts

**Settings ▸ Rotation**: 0° / 90° / 180° / 270°, to match how the pad sits on
your desk. When you rotate:

- the on-screen key grid turns with it, so what you edit matches what the
  device shows;
- key icons are re-rendered rotated — lossless, since the source art is
  square;
- the transient overlays follow the new orientation too: at 90° / 270° the
  emoji-browser and screensaver scroll keys become left / right instead of
  up / down.
